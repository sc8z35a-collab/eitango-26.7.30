# Glass Vocab — スマホ専用 英単語学習アプリ

片手のスマホ操作だけで「覚える → 思い出す → 定着させる」を回せる、**単一HTMLファイル完結**の英単語学習Webアプリです。
リキッドグラス（Liquid Glass）風UI + CSS 3D Transform を採用し、外部CDN・外部画像・外部フォントは一切使用していません。

## 2つのバージョン（機能は同一・学習データは共有）

| ファイル | 位置づけ | 特徴 |
| --- | --- | --- |
| `index.html` | **標準版（軽量）** | 必要十分な3Dとアニメーション。動作が軽い |
| `pro.html` | **Pro版（高精細3D・微細アニメーション）** | 材質・奥行き・動きを全面強化した上位版。**追加コンテンツ「Word Plus」**と**「共通テスト対策キット」**（いずれもデモ購入）を搭載 |
| `exam.html` | **共通テスト対策キット専用ページ**（Pro版のメニューから購入・起動） | 別デザイン（Ink & Paper）の最新UI。**学習データは index/pro と完全独立**（別 localStorage キー） |

- `index.html` と `pro.html` は同じ `localStorage` キー（`glassvocab.v1`）を使うため、**進捗・XP・バッジは両版で共通**です。
- `exam.html` だけは **`gvexam.v1`** を使い、本編の XP・レベル・SRS・履歴には一切影響しません（購入権利のみ Pro版から書き込み）。
- 相互リンク: 標準版のホーム下部／設定に「Pro版を開く」、Pro版の設定に「標準版を開く」。
- 想定端末幅: 375〜430px。それ以上の幅では画面中央に幅430pxのモバイル枠として表示
- 目標: 1セッション5〜10分。通学・通勤中の片手操作

### Pro版で強化した点（`pro.html`）
**高精細マテリアル**
- ガラスの3層構造を強化：`blur(24px) saturate(150%) brightness(1.02)` ＋ 4段重ねのドロップシャドウ ＋ 内側ベベル ＋ 下辺の落ち込み陰
- **縁を走る光**を `mask-composite` による1pxグラデーション枠（`.rim-light`）で実装（非対応環境は `@supports` で自動的に無効）
- **鏡面ハイライト2灯**（上方向の主光＋下方向の回り込み光）が指の位置・端末の傾きで移動
- 端末の解像度に応じてヘアラインを 1px / 0.5px に切替（`min-resolution: 2dppx`）
- 無彩色の**フィルムグレイン**（SVG `feTurbulence` を静的に1枚だけラスタライズ）で材質の解像感を付与
- 背景ブロブを5個＋メッシュ状の多点グラデーションに増強（`color-mix` 対応環境のみ、フォールバックあり）

**3D表現**
- カード側面を**9層のスラブ**に分割し、光の減衰を段階的にして「板」ではなく「塊」に
- 面の内側で**要素ごとにZを変える視差レイヤー**（品詞14px / 単語34px / 発音22px / ヒント10px）
- **独立した接地影レイヤー**がカードの傾き・移動に追従（`translate` + `scale` + `opacity`）
- 奥のカードに**被写界深度のぼかし**（0.7px刻み）。手前に来た瞬間に解除
- デッキは Z を深くとり、わずかな回転を加えて手積みの表情を再現
- スワイプは**3軸追従**（rotateZ / rotateX / rotateY）＋Z持ち上げ、離すと**バネで戻る**（行き過ぎのある `cubic-bezier(.22,1.28,.36,1)`）
- 飛ばすときは弧を描いて手前に抜け、わずかにぼける

**微細アニメーション**
- 単語は**1文字ずつ**奥から立ち上がる（24msずつ遅延／文字は常に正面）
- カードの登場は**奥から順にせり上がる**スタガー（70msずつ）
- フリップは中間で**Zに浮き上がる**（`flipLift` / `flipBack`）
- 画面遷移は奥から手前への持ち上げ、リスト・選択肢・シート内容は**順次立ち上げ**
- 数値は**カウントアップ**（XP・レベル・語数・正答率・デイリー進捗）
- タブバーは**形が追従するインジケータ**（実測してバネで移動）＋アイコンのスプリング
- 押した位置に光が集まる**フィードバック**（ホバー非依存）
- 正解＝軽いポップ／不正解＝短いシェイク、コンボ更新でバッジが1回だけ拍動
- レベルアップは**二重の衝撃波リング＋22個の大小の光の粒**（奥行き違い・無彩色）、XP数字は残像付きで手前へ
- ゆっくり通り過ぎる**鏡面反射スイープ**（6.4s周期）
- スクロール終端をマスクでやわらかく落とし、内容が「切れて」見えないように

※ 追加した演出はすべて `prefers-reduced-motion: reduce` と設定「動きを減らす」で**完全停止**します（検証済み）。ネオン・発光色は一切使っていません（すべて無彩色または黒の透過）。

## 1. 実装方針の要約（5行）

1. 単一HTMLに、データ→保存→XP→SRS→UI→ジェスチャー→演出の順で層を分け、Vanilla JSのIIFEで完結させた。
2. 3Dは `perspective` を「実際に立体を見せる親（`.sess-body` / `.ring-stage` / `.fx` / `.badges`）」に個別付与し、`transform`・`opacity` のみをアニメーションして60fpsを確保。
3. リキッドグラスは `.glass` 1クラスに集約（半透明＋blur＋1pxボーダー＋insetベベル＋大きな影＋`::before`の光沢）し、**ガラスの入れ子を禁止**。文字は `--plate` の不透明レイヤー上に置いてAAコントラストを担保。
4. 配色はネオン・発光を完全排除（彩度60%以下の藍/セージ/テラコッタ）。高揚感は明度差・スケール・奥行き（translateZ）だけで表現。
5. `prefers-reduced-motion` と設定トグルの両方を `MOTION()` 1関数に集約し、3D回転・視差・飛び出し・背景の動きをまとめてフェードへ差し替え。

## 2. 実装済み機能

### スマホ特化
- `viewport-fit=cover` + `safe-area-inset-*`（上部インジケータ / 下部タブバー）
- 高さは `100dvh`（`100vh` 不使用）
- 主要操作はすべて画面下1/3（サムゾーン）。上部は情報表示のみ（レベル・XPバー・コンボ・ストリーク・トースト）
- タップ領域は最小48×48px、`:hover` は装飾の保険のみ
- ジェスチャー: 左スワイプ=わからない / 右スワイプ=わかる（指に追従して移動・傾き、離すと飛んでいく）/ 上スワイプ=詳細ボトムシート / タップ=3Dフリップ
- Vibration API による触覚フィードバック（正解・不正解・スワイプ確定・レベルアップ / 設定でOFF）
- `overscroll-behavior:none` と `touch-action:manipulation` で引っ張って更新や誤操作を抑止しつつ、利用者のピンチズームは利用可能
- 入力欄は16px以上（iOSの自動ズーム防止）、`inputmode` / `autocapitalize="off"` / `autocorrect="off"` 指定
- PWA: manifestをインラインdata URIで動的生成（standalone / portrait / theme-color / SVGアイコン）
- 下部固定のガラス製タブバー（ホーム／学習／単語帳／実績）

### 3D・立体表現
- ルート `perspective:1200px` + `transform-style:preserve-3d`
- カードデッキの奥行き（最大4枚が `translateZ`/`scale` で後退、1枚消化で奥のカードがせり上がる）
- 3Dフリップ（Y軸180度）＋厚み（6枚のスラブ層で側面を表現）
- ジャイロ視差（DeviceOrientation、最大±8度。**許可を求める前に説明モーダル**、設定でOFF）
- 3Dリング状の単語帳（円筒配置＋横スワイプ回転＋スナップ、文字は逆回転で常に正面＝可読性優先）
- レベルアップ演出（`Lv n` プレートが手前に飛び出してフェード＋無彩色の光の粒14個）
- 獲得XPの数字が3D空間の手前へ飛び出してフェード
- `prefers-reduced-motion: reduce`／設定「動きを減らす」で3D・視差・飛び出しを全停止しフェードに置換（リング表示は縦並びの可読リストへ）

### ポイント・ゲーミフィケーション
- XP: 正解+10 / スペル正解+15 / 初見の単語を習得+30 / デイリーゴール達成+50
- コンボ: 3連続でx1.2 → 6でx1.5 → 10でx2.0、不正解でリセット。上部ガラスバッジに表示
- レベル制: 必要XP `round(80 × 1.22^(Lv-1))` の緩やかな指数カーブ
- デイリーゴール: 10/20/30/50語から選択、円形リングゲージ、達成でボーナスXP
- ストリーク: 表示のみ。途切れても「またここから始めよう。いつでも大丈夫。」と穏やかな文言（煽り・叱責なし）
- 実績バッジ10種（獲得=立体的／未獲得=すりガラス越しのシルエット）
- 週間サマリー: 7日分の獲得XP棒グラフ
- すべて `localStorage` に保存（リロード復元）。課金・ガチャ・時間制限は一切なし

### 学習機能
- 単語カード（スワイプ／ボタン両対応の自己採点）
- 4択クイズ（英→和 / 和→英、同レベル語からダミー生成）
- スペル入力（頭文字＋マスクのヒント表示）
- ミックス（4種を順に混在）
- 間隔反復（SM-2簡易版）と「未学習／学習中／習得済み」の3段階管理
- 苦手単語だけの復習モード
- レベル別単語帳（初級30・中級30・上級30＝**90語**）
- 各単語に発音記号・品詞・意味・例文（英日）
- Web Speech API による単語／例文の読み上げ（速度3段階、自動読み上げON/OFF）

### アクセシビリティ
- 半透明の上の文字は不透明プレート（`--plate`）を敷いてWCAG AA（4.5:1）以上を確保
- `prefers-reduced-transparency: reduce` でガラスを不透明面にフォールバック
- `@supports not (backdrop-filter)` のフォールバック
- スワイプ操作には必ずボタンの代替（わからない／裏返す／わかる／詳細）
- 英単語 2.1rem・例文 1.02rem、日本語はNoto Sans JP系→システム日本語、英語はsystem-ui/Inter系のフォールバック
- ライト/ダーク自動切替（`prefers-color-scheme`）、`role="tablist"`・`aria-selected`・`aria-checked`・`aria-live` 等の付与

## 3. 機能エントリURI（パスとパラメータ）

静的サイトのため単一ページです。ハッシュで初期タブを指定できます。

| URI | 動作 |
| --- | --- |
| `index.html` | 標準版ホーム（デイリーリング・進捗サマリー） |
| `index.html#home` / `#study` / `#book` / `#stats` | 標準版の各タブを直接開く |
| `pro.html` | **Pro版**ホーム（高精細3D・微細アニメーション） |
| `pro.html#home` / `#study` / `#book` / `#stats` | Pro版の各タブを直接開く（`#home` に2枚のストアカード、`#study` に「長文読解」と「共通テスト対策」） |
| `exam.html` | **共通テスト対策キット専用ページ**。未購入なら購入案内（ロック画面）、購入済みならトップ（得点リング・長文3本） |

※ ハッシュは `home`（ホーム）／`study`（学習メニュー）／`book`（単語帳）／`stats`（実績）の4種。`index.html` / `pro.html` で共通です（`exam.html` は独自の画面遷移を使います）。

開発・デバッグ用フック（コンソールから呼べます）:

- `__gv.view('study'|'home'|'book'|'stats')` — ビュー切替
- `__gv.start({mode:'card'|'quiz_en'|'quiz_ja'|'spell'|'mix', levels:['beginner','intermediate','advanced'], n:10, weak:false})` — セッション開始
- `__gv.sheet('b01')` — 単語詳細シートを開く（IDは `b01`〜`b30` / `i01`〜`i30` / `a01`〜`a30`）

## 5. 使い方

1. `index.html` をスマホのブラウザで開く（iOSは「ホーム画面に追加」でスタンドアロン起動）。
2. ホームの **学習をはじめる** → 学習メニューでモード・レベル・出題数を選び **このセッションを始める**。
3. 単語カード:
   - **タップ** で裏返す（意味・例文）
   - **右スワイプ / わかるボタン** = わかる（+10XP）
   - **左スワイプ / わからないボタン** = わからない
   - **上スワイプ / ↑ボタン** = 詳細ボトムシート（例文の読み上げ・出題履歴）
4. 4択・スペル入力は下部の選択肢／入力欄で回答（スペル正解は+15XP）。
5. 単語帳タブ: 検索・レベル/苦手フィルタ、**3Dリング表示**は横スワイプ（または◀▶）で回転、タップで詳細。
6. 実績タブ: レベル、週間XPグラフ、バッジ。**設定を開く** から触覚・傾き視差・動きを減らす・読み上げ速度・デイリーゴール・データ初期化。

### 単語データの追加方法
1. `index.html`（Pro版なら `pro.html`）の `RAW` を探します（`var RAW = {` の行）。両方を使うなら**同じ行を両ファイルに**追加してください。
2. 追加したいレベルの配列末尾に、次の6要素の配列を1行足します。
   ```js
   ["mitigate","/ˈmɪtɪɡeɪt/","動","軽減する・緩和する","We took steps to mitigate the damage.","損害を軽減する対策を取った。"],
   ```
   - 順番は `[単語, 発音記号, 品詞, 意味(日), 例文(英), 例文(日)]`
   - 末尾の行のカンマ有無に注意（最後の行はカンマ不要）
3. 保存してリロードすれば即反映されます（IDは自動採番、既存の学習記録は保持されます）。
4. 新しいレベルを増やす場合は `RAW` にキーを追加し、`LV_JA`（表示名）にも同じキーを追加してください。フィルタ用ピルは `renderBook()` / `renderMenu()` の配列に1項目追加します。

### 長文・文章題の追加方法（Pro版 / Word Plus）
1. `pro.html` の `var PASSAGES = [` を探します。
2. 配列末尾に次の形のオブジェクトを追加します（`id` は既存と重複しない文字列）。
   ```js
   { id:'pg4', title:'Why We Forget', titleJa:'忘れることの意味', mins:3,
     paras:[ ['English paragraph 1…','日本語訳1…'], ['…','…'] ],
     qs:[ { t:'内容一致', q:'本文の内容に合うものはどれですか。',
            c:['選択肢A','選択肢B','選択肢C','選択肢D'], a:1, e:'第2段落に根拠があります。' } ] }
   ```
   - `a` は `c` 配列内の**正解のインデックス**（表示時に自動シャッフルされます）
   - `e` は回答後に表示される日本語の解説
   - 段落数・問題数は自由（一覧の「◯問」表示は自動計算）
3. 追加単語は `var PLUS_WORDS = [` の末尾に `RAW` と同じ6要素の配列を足すだけです（IDは `p41`… と自動採番）。
4. ストアカードに書かれた「40語／3本／24問」の文言は `inclRows()` に定数として入っているため、数量を変えたらそこも書き換えてください。

### 共通テスト対策キットの長文・問題の追加方法
1. `js/exam-data.js` の `passages` 配列末尾に、上記の形のオブジェクト（`id` は `e4`…）を追加します。HTMLの编集は不要です。
2. 小問は `qs[].items[]` に追加。`id` は全体で一意（`q23`…）にし、`pt` の合計が 100 になるよう配点を調整します（合計は自動集計され、得点リングに反映）。
3. `exp`（解説）・`gram`（文法）・`vocab`（`[語, 発音記号, 意味]` の配列）を埋めると、解説シートの3タブ・語彙シート・文法一覧に自動で並びます。
4. `field` は `EXAM_KIT.fields` のキー（出題タイプ）。新しいタイプを使うなら `fields` に1行追加すると、結果画面のレーダーチャートの軄が自動で増えます。
5. Pro版のストア表記（「長文3本／全10問（小問22）」や価格）は `pro.html` の `EXAM` 定数と `inclRows()` にあるため、数量を変えたらそこも書き換えてください。
